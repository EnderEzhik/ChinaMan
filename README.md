# ChinaMan

Приложение для учета фильмов.

## О проекте

Проект помогает хранить данные о фильмах в четырех категориях:
- просмотренные;
- смотрю;
- хочу посмотреть;
- заброшенные.

Так как фильмы могут пересматриваться, для каждого фильма важно отслеживать:
- количество просмотров;
- дату последнего просмотра;
- среднюю оценку.

## Особенности реализации

В проекте используется рефлексия и `Activator.CreateInstance` для создания универсальных элементов управления окнами.

Например, одна и та же кнопка открывает нужное окно в зависимости от текущего контекста. Контекст хранит изменяемый во время работы приложения тип окна, получаемый через `typeof(...)`.

## Хранение данных

Для хранения данных используется локальная база данных `SQLite`.

Доступ к данным реализован через ORM `Entity Framework Core`.
